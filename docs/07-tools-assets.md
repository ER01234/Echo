# 07. Инструменты: арт, звук, хостинг (бюджетный набор)

Принцип: **0 USD обязательных расходов**. Всё, что идёт в билд, должно быть либо CC0, либо сгенерировано/сделано вами с лицензией, допускающей коммерческое использование (ориентир задания — Steam). Каждый ассет вносится в `docs/CREDITS.md` (источник, лицензия, дата).

> Условия бесплатных тарифов и лицензий меняются. Перед использованием ассета или генератора **проверьте актуальные условия** на сайте сервиса и сохраните скриншот или ссылку в `CREDITS.md`.

## 1. Хостинг (решено: GitHub)

| Что | Решение |
|---|---|
| Репозиторий | GitHub, публичный (бесплатно, и код можно дать в анкете) |
| Хостинг игры | **GitHub Pages** через GitHub Actions (бесплатно для публичных репозиториев) |
| URL | `https://<ваш-ник>.github.io/echo/` |
| Резерв | itch.io (HTML5, загрузка zip с `dist`) |
| Vite | `base: './'` в `vite.config.ts`, чтобы пути работали в подкаталоге |
| Ванпейджер | GitHub Pages: страница `/onepager/` в той же сборке (HTML+CSS, одна страница) или Google Docs с доступом по ссылке |

Преимущество: игроку (проверяющему) регистрация не нужна, а ссылка живёт постоянно. Одностраничный ванпейджер прямо в проекте — меньше внешних зависимостей.

## 2. Арт (главная статья экономии: «финальный арт не обязателен»)

Приоритет: **читаемость и единый стиль**, а не детализация.

| Способ | Стоимость | Когда | Заметки |
|---|---|---|---|
| **Kenney.nl** (наборы 2D) | Бесплатно, CC0 | Основа: тайлы, UI, иконки, частицы | Лицензия CC0, атрибуция не нужна |
| **OpenGameArt.org** | Бесплатно, лицензии разные | Дополнение | Брать только CC0 / CC-BY, писать авторов |
| **Свои плейсхолдеры в коде** (Phaser Graphics: круги, ромбы, цветные силуэты) | Бесплатно | Враги, снаряды, эффекты | Стиль «геометрический неон» — проще всего сделать единым, быстро и читаемо |
| **Aseprite** (платный) или **LibreSprite / Piskel** (бесплатно) | 0 | Ручная доработка спрайтов | Piskel работает в браузере |
| **Генерация изображений** (бесплатные тарифы, например Bing Image Creator / Microsoft Designer, Leonardo.ai Free) | 0 | Фоны, иллюстрация для ванпейджера, обложка | Проверить условия коммерческого использования бесплатного тарифа. Для самих спрайтов генераторы подходят плохо: нет единообразия |

**Рекомендация:** стиль «геометрический неон» (силуэты из примитивов, палитра 16 цветов, свечение) + иконки Kenney + 1-2 сгенерированных фона на биом. Это дёшево, читаемо и выглядит цельно. Концепция «Эхо» (прозрачные призраки) с таким стилем сочетается естественно.

## 3. Звук

| Тип | Решение | Стоимость | Заметки |
|---|---|---|---|
| Эффекты | **ZzFX** (в коде) и **jsfxr** (генератор в браузере) | 0 | Размер минимальный, лицензия свободная (проверить текст лицензии репозитория) |
| Музыка | **Kenney Audio** (CC0), **OpenGameArt** (CC0 / CC-BY), **Pixabay Music** (по лицензии Pixabay) | 0 | Нужно 2-3 трека: меню/хаб, бой, босс. Формат OGG, до 1-1.5 МБ на трек |
| Альтернатива | Процедурная музыка через Web Audio (простые арпеджио в коде) | 0 | Запасной вариант, если не найдётся подходящих треков |

**Осторожно с AI-музыкой (Suno, Udio):** бесплатные тарифы обычно разрешают только некоммерческое использование. Для ориентира «Steam» это риск. Если захотите использовать, нужен платный тариф с коммерческими правами, и это надо проверить заранее.
