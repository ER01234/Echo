## Принципы (чтобы выглядело убедительно и было правдой)

1. Для каждой записи: **что поручил** -> **что получил** -> **как проверил** -> **что решил сам/исправил**.
2. Фиксируйте случаи, когда AI ошибся. Это усиливает доверие.
3. Решения по дизайну (что делать и зачем) принимаете вы. Отмечайте их отдельно.
