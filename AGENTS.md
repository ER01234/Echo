# AGENTS.md — правила проекта ECHO

Проект: браузерный action-roguelite «ECHO» для тестового задания GamesUp42 (вакансия разработчика игр). Подробности в `docs/`.

## Главное
- Язык общения с пользователем: **русский**. Код, имена, комментарии к коду: английский.
- **Начни с чтения `STATE.md`**, затем при необходимости `docs/04-roadmap.md` и `docs/02-game-design.md`.
- Делай **одну задачу из дорожной карты за сессию** (ID вида `1.4`). Не расширяй объём.
- После задачи: тесты и сборка зелёные -> обнови `STATE.md` -> допиши строку в `docs/06-ai-log.md` -> коммит.

## Жёсткие ограничения
- Phaser **закреплён на 3.90.0** (точная версия, без `^`). Не обновлять и не мигрировать на Phaser 4.
- TypeScript `~5.9`, Vite `^7`, Vitest `^3`. Не обновлять мажорные версии без запроса.
- `src/sim/` **не импортирует Phaser** и не использует `Math.random()`, `Date.now()`, DOM. Только seed-RNG.
- Все игровые числа живут в `src/data/`. Никакого hardcode баланса в логике.
- Никаких внешних CDN и сетевых запросов в рантайме. Шрифты и ассеты — локально.
- Игра должна работать без регистрации, без бэкенда, без скачивания.
- Ассеты только CC0 или собственные. Каждый внесён в `docs/CREDITS.md`.
- Не переписывай архитектуру (`docs/03-tech-architecture.md`) без явного запроса пользователя.

## Среда (Windows, PowerShell)
- Выполнение `.ps1` отключено: используй **`npm.cmd`** и **`npx.cmd`**, а не `npm`/`npx`.
- Node v24, npm 11, git 2.45. Нет `pnpm` и `gh`.
- Рабочая папка: `C:\Users\Роман\Desktop\Игра`.
- Для чтения файлов используй инструмент `read`, для поиска `grep`/`glob`.

## Команды (после этапа 0)
```
npm.cmd run dev       # локальный сервер
npm.cmd run build     # сборка в dist/
npm.cmd run test      # vitest
npm.cmd run lint
npm.cmd run balance   # бот-симуляция баланса
npm.cmd run e2e       # playwright
```

## Стиль работы
- Маленькие чистые модули, тесты рядом (`tests/unit/`).
- Не ломай существующие тесты. Если меняешь поведение, обнови тест и объясни почему.
- Не придумывай факты о проверке: если не запускал тест или игру, так и скажи.
- Если задача требует решения по дизайну, которого нет в `docs/`, **спроси пользователя**, не додумывай.
- Список «режем первым» в `docs/02-game-design.md` (раздел 13) — единственный разрешённый порядок сокращения объёма.

## Definition of Done любой задачи
1. Код и тесты написаны.
2. `test`, `lint`, `build` проходят.
3. Для визуальных изменений: запущено в браузере и осмотрено (скриншот через Playwright допустим).
4. `STATE.md` обновлён, запись в `06-ai-log.md` добавлена, коммит сделан.
