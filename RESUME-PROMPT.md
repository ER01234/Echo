# RESUME-PROMPT — как переоткрыть проект в новом чате

## Шаги
1. Откройте DeepSeek Harness, в качестве рабочей папки выберите `C:\Users\Роман\Desktop\Игра`.
2. Начните новый чат с моделью DeepSeek 4.1.
3. Вставьте один из промптов ниже.

---

## Промпт A: стандартное продолжение (копировать целиком)

```
Продолжаем проект ECHO (браузерный roguelite для тестового задания GamesUp42).
Рабочая папка: C:\Users\Роман\Desktop\Игра. Общайся со мной на русском.

Сначала прочитай по порядку: AGENTS.md, STATE.md, затем docs/04-roadmap.md.
По необходимости: docs/02-game-design.md, docs/03-tech-architecture.md.

Правила: следуй AGENTS.md (Phaser закреплён на 3.90.0, sim без Phaser, npm.cmd вместо npm).
Возьми задачу из раздела «Следующая задача» в STATE.md и выполни ТОЛЬКО её.
Сначала кратко изложи план (3-6 пунктов) и дождись моего «ок», если задача нетривиальна.
По завершении: запусти test/lint/build, обнови STATE.md, допиши строку в docs/06-ai-log.md, сделай git commit.
Не придумывай результаты проверок. Если чего-то не запускал, так и скажи.
```

---

## Промпт B: конкретная задача

```
Контекст проекта: прочитай AGENTS.md и STATE.md.
Выполни задачу <ID из docs/04-roadmap.md> (например, 1.4). Ничего сверх этого.
Критерий готовности указан в дорожной карте. Покажи, как ты его проверил.
```

## Промпт C: проверка состояния («где мы?»)

```
Прочитай STATE.md и docs/04-roadmap.md. Просмотри git log и дерево проекта.
Скажи, что реально сделано, чем это отличается от записанного в STATE.md,
и какая следующая задача. Код не меняй.
```

## Промпт D: ревью перед сдачей

```
Проведи ревью готовности к отправке по docs/05-submission.md (чек-лист) и критериям из docs/01-requirements.md.
Для каждого пункта: выполнено / не выполнено / не проверено, с доказательством.
Особо проверь: прямая ссылка без регистрации, 30+ минут контента, ошибки в консоли, ванпейджер.
```

---

## Советы для работы с DeepSeek 4.1
- Один чат = одна задача. Контекст не раздувается, меньше ошибок.
- Закончили задачу: проверьте глазами, `git commit`, обновлён `STATE.md`, новый чат.
- Если модель «забыла» правила, напомните: «перечитай AGENTS.md».
- Если модель предлагает обновить Phaser, сменить архитектуру или добавить бэкенд — отклоните.
- Большие независимые куски (например, данные врагов) можно отдавать подагентам, но не пересекающимся по файлам.

```

  RESUME-PROMPT.md     этот файл
  docs/
    01-requirements.md       требования ТЗ и критерии
    02-game-design.md        геймдизайн ECHO
    03-tech-architecture.md  стек, архитектура, тесты, деплой
    04-roadmap.md            задачи по этапам с DoD
    05-submission.md         черновики анкеты и ванпейджера, план на 6 мес.
    06-ai-log.md             журнал AI (вести по ходу)
    07-tools-assets.md       бюджетные инструменты: арт, звук, хостинг
    source/gamesup42-tz.html исходная страница ТЗ
```
